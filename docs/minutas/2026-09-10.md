# 2026-09-10 — Reescritura para la instancia de aprobación

- **Participantes**: Tiziano Messina
- **Canal**: Discord, informando a Jeremías
- **Reconstruido de**: pull requests #3 a #13

## Contexto

La regularidad ya estaba aprobada, así que el objetivo pasó a ser la **aprobación en examen**, que
exige bastante más: acceso con dos niveles de permisos, tests automatizados, ambientes, documentación
de la API y despliegue funcionando.

Una revisión del estado real encontró que faltaban cosas de fondo: la migración de Prisma no estaba
versionada, no había datos de carga inicial, ninguna ruta estaba protegida y el cálculo del precio de
la solicitud siempre daba cero.

## Decisión de fondo

El vocabulario original era incorrecto: "prestamista" es quien presta dinero, no quien presta un
servicio rural. Se renombró todo a **productor** y **contratista**, en la base, la API, el código y la
interfaz. Se aprovechó que no había datos reales para rehacer el modelo con una migración limpia.
