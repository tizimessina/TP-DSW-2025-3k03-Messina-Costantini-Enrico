## Decisiones

- El repositorio es un **monorepo**: backend y frontend en el mismo proyecto, para compartir tipos y
  no tener que sincronizar dos historiales.
- Se trabaja sobre `main` con commits directos en esta primera etapa; las ramas y los pull requests
  se incorporan más adelante, cuando el proyecto crece.
